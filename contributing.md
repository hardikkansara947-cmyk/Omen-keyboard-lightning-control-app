# Contributing to OMEN Lighting Control

Thank you for your interest in helping improve this tool! Here is a quick guide to getting started.

## Getting Started
1. Fork the repository.
2. Clone your fork locally:
   ```bash
   git clone [https://github.com/YOUR-USERNAME/Omen-keyboard-lightning-control-app.git](https://github.com/YOUR-USERNAME/Omen-keyboard-lightning-control-app.git)
   cd Omen-keyboard-lightning-control-app

    Test the script locally:
    Bash

    python3 omen-controller.py

Contribution Ideas

    Adding support for 4-zone RGB keyboards

    Improving Tkinter / CustomTkinter UI styling

    Packaging for Arch Linux (AUR) or Fedora (RPM)

    Adding temperature/fan speed monitors via psutil or hwmon

    Bug fixes and translation support

Submitting Changes

    Create a feature branch (git checkout -b feature/my-new-feature).

    Commit your changes (git commit -m "Add feature XYZ").

    Push to the branch (git push origin feature/my-new-feature).

    Open a Pull Request detailing what changed.


---

### 2. Create Issues with the `good first issue` Label
New contributors search GitHub specifically for repositories with beginner-friendly task labels.

1. Go to the **Issues** tab on the repository.
2. Click **New Issue**.
3. File distinct tasks, for example:
   * **Issue 1:** *"Add CLI argument parser for setting individual zone colors"*
   * **Issue 2:** *"Convert Tkinter interface to modern CustomTkinter"*
   * **Issue 3:** *"Add RPM packaging script for Fedora users"*
   * **Issue 4:** *"Improve dark-mode styling and layout responsiveness"*
4. In the right-hand sidebar of each issue, set the **Labels** to:
   * `good first issue`
   * `help wanted`

GitHub automatically indexes repos that have these tags in aggregator tools and developer discovery pages.
