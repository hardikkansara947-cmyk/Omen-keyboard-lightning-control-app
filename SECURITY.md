# Security Policy

## Supported Versions

We release patches and security fixes for the latest release branch.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security issue (such as a privilege escalation bug in sudoers rules or script injection vulnerabilities), please do **not** open a public issue.

Instead, please report it via one of these private channels:
- **GitHub Private Advisory:** Go to the [Security Advisories](https://github.com/hardikkansara947-cmyk/Omen-keyboard-lightning-control-app/security/advisories) tab and click **Report a vulnerability**.
- **Email:** Contact the maintainer directly at your contact email.

Please include:
- Steps to reproduce the issue
- Affected OS version and laptop model
- Potential security impact

We will review reports within 48 to 72 hours and work on a fix before public disclosure.
